# Triangle Sketcher

A simple Rust program that draws ASCII triangles.

## What it does

This program prompts the user to enter the number of rows for a triangle and then prints an ASCII triangle pattern using asterisks (*).

## How to run

1. Make sure you have Rust installed
2. Navigate to the project directory
3. Run the program:
   ```
   cargo run
   ```

## Example

When you run the program and input `5`, it will output:
```
    *
   ***
  *****
 *******
*********
```

The triangle is centered and each row has an odd number of asterisks (1, 3, 5, 7, etc.).
